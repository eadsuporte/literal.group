About Kopere BI - 100+ Reports and Dashboards for Moodle

Kopere BI is a reporting and dashboard plugin for Moodle with more than 100 ready-to-use reports.

It helps administrators, managers, instructors and educators understand Moodle data through visual dashboards, charts, tables, maps and information blocks. The plugin was designed to make Moodle reports easier to access, easier to read and more useful for decision-making.

Kopere BI can be used to analyse students, courses, enrolments, revenue, access logs, grades, activities, quizzes, forums, SCORM packages, assignments, feedback, competencies, badges and other important learning indicators.

Main purpose

Kopere BI was created for Moodle sites that need practical reports without depending only on raw database queries or standard Moodle reports.

It is especially useful for schools, universities, companies and training providers that need to monitor learning indicators in a more visual and organised way.

Features

Kopere BI provides different ways to display Moodle data, from simple summary cards to advanced interactive reports.

Visual dashboards

Reports can be organised into dashboards, making it easier to follow key indicators in one place. Dashboards can include charts, tables, maps, information cards and custom HTML layouts.

Charts and visual reports

Kopere BI uses ApexCharts to display interactive and responsive charts. These charts help users quickly understand trends, comparisons and distributions.

  • Area charts: useful for showing trends over time, such as student progress, course activity or access volume.
  • Column charts: useful for comparing courses, groups, categories, modules or other indicators.
  • Line charts: useful for following changes over time and identifying patterns in activity, completion or performance.
  • Pie charts: useful for showing proportions, percentages and distributions.

Interactive tables

Kopere BI can display report data in interactive tables using DataTables. This is useful for reports with many records, such as users, courses, enrolments, completions, logs, grades or financial data.

  • Pagination: splits large reports into pages.
  • Search and filtering: helps users quickly find specific information.
  • Column sorting: makes it easier to compare and organise data.
  • Export options: allows data to be exported for external use.

Export options may include print, PDF, Excel, CSV and copy to clipboard, depending on the report configuration.

Information cards

Reports can also be displayed as small information blocks. These blocks are useful for showing key numbers such as total users, active students, completed courses, pending activities, revenue indicators or other important metrics.

Custom HTML reports

Kopere BI supports custom HTML output with Mustache. This allows each report to have its own layout and visual presentation.

With Mustache templates, the same data can be presented as cards, lists, summaries, dashboards or any other layout required by the institution.

Maps

Kopere BI can display map-based reports, including user location information based on IP data when available.

Examples of use

  • Monitor student engagement and access.
  • Analyse course activity and content usage.
  • Follow enrolments, learners and revenue indicators.
  • Track grades, assessments and completion progress.
  • Review quiz, questionnaire, forum, SCORM and assignment activity.
  • Create management dashboards for Moodle administrators and coordinators.
  • Present Moodle data in charts, tables, cards, maps and custom layouts.

Who is this plugin for?

Kopere BI is intended for Moodle administrators, course managers, educators, coordinators and institutions that need clearer and more flexible reports.

It is useful for anyone who needs to understand Moodle data without relying only on technical database access or isolated standard reports.
