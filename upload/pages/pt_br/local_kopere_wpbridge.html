Ponte entre WooCommerce e Moodle.

Recursos

  • Mapear IDs de produtos WooCommerce para cursos Moodle
  • Mapear IDs de produtos WooCommerce para coortes Moodle
  • Receber webhooks de pedidos com validação por token
  • Validar assinatura HMAC do WooCommerce
  • Tarefa agendada para ressincronizar vendas concluídas
  • Criar automaticamente usuários Moodle quando não existirem
  • Inscrever usuários por inscrição manual
  • Adicionar usuários a coortes
  • Enviar notificações por e-mail pela API de mensagens do Moodle

Configuração obrigatória

  • URL da loja
  • Consumer key do WooCommerce
  • Consumer secret do WooCommerce
  • Inscrição manual habilitada nos cursos de destino

Páginas principais

  • /local/kopere_wpbridge/
  • /local/kopere_wpbridge/mappings.php
  • /admin/settings.php?section=local_kopere_wpbridge

Endpoint do webhook

A página de configurações mostra a URL completa com token.

Exemplo:

https://moodle.example.com/local/kopere_wpbridge/webhooks.php?token=...
